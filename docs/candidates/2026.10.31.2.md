# Frank Energie 2026.10.31.2 — GraphQL diagnostics HACS TEST candidate

**Status:** qualified pre-release only; synthetic CI evidence is not proof of
live Frank Energie API completeness or Belgian billing correctness.
**Base:** includes v2026.10.31.1 plus follow-up draft PR #14 and #16.
**Pinned client:** `python-frank-energie==2026.9.20`.

## Purpose

Diagnose **actual GraphQL calls** to Frank Energie, not only downstream Home
Assistant coordinator health. Distinguish the anonymous BE market-price
source from the authenticated customer tariff, source response completeness,
client parsing, and final selected/merged price slots.

The built-in HA diagnostics feature exports the last 96 in-memory source
events (no extra HTTP calls), including:

- Logical GraphQL operation, source client, UTC timestamp, query calendar
  period (when safely formatted) and elapsed milliseconds.
- `ok`, `empty_response`, `graphql_errors` and `exception`; HTTP failure
  status only if exposed by the pinned client's chained exception.
- Recognized response fields (`null`/`empty`/`present`), and raw electricity
  and gas price slot counts for the public and customer `MarketPrices` calls.
- Parsed `PriceData.all` counts and final `public`, `customer`, `mixed`,
  `public_fallback`, or `not_available` selection evidence.
- Separate settings, prices and statistics coordinator health; month summary,
  invoices, usage and optional `MonthInsights` availability.
- Belgian `MODEL` variable contract and opaque `SMR1`/`SMR3` meter codes,
  with explicit separation from user-confirmed physical digital gas meter.

Complete raw source provider objects, configuration payloads and account
options are **excluded** from the new diagnostics output. It only exposes
bounded diagnostic metadata and relevant sanitized flags. No query variables,
headers, tokens, EAN, invoice amounts or other private raw response fields
are deliberately retained. Review the export before wider sharing.

## How to capture

In HA: Settings → Devices & services → Frank Energie → ⋮ → Download diagnostics.
Run once after restart and again after an expected normal price/statistics
refresh. For day-ahead prices, capture around the known publication window.
This trace resets on HA restart and retains 96 recent events; it is not a
long-term monitoring database.

**Do not enable `python_frank_energie: debug` on a real account.** The
upstream library logs raw MonthSummary responses at DEBUG, and may log raw
GraphQL error content at other levels. Use bounded diagnostics instead.

For source-level interpretation and privacy see
[diagnostic-observability.md](../diagnostic-observability.md).

## Open issues and acceptance

1. `MonthInsights` zero-vs-missing ambiguity in pinned upstream client
   remains issue #11. Monthly finance remains opt-in OFF.
2. Real Belgian cost/source reconciliation, utility reporting and Recorder
   consistency are not established by these tests.
3. A physical digital gas meter is **confirmed**, but the Frank API reports
   gas connection `unknown`, `SMR1`, and no last reading date. This does
   not establish missing hardware; validate actual gas-data publication lag.
4. A successful price coordinator poll does not establish actual customer
   tariff slots. With MODEL (variable) contracts public spot prices must not
   be presented as actual contractual unit prices.
5. Successful HTTP response codes are not exported because the pinned
   client's `_query` return value contains JSON and hides the `aiohttp`
   response status. Only exposed HTTP **error** codes are recorded.

## Install / rollback

Install the full `frank_energie.zip` asset through the established HACS custom
repository (qualified prerelease), then restart HA. Preserve the configuration
entry and entity registry. Before installation, back up the current integration
and Home Assistant configuration. Rollback by restoring the entire previous
integration directory/release and restarting; do not merge files across versions.

The published `v2026.10.31.1` stays immutable. Do not promote this to stable
without actual Home Assistant diagnostic evidence and finance reconciliation.
