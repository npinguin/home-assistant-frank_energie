# Frank Energie 2026.11.1.6 — market-hour automations and API health

**HACS TEST prerelease only.** Source-verified candidate from the existing
[PR #18](https://github.com/npinguin/home-assistant-frank_energie/pull/18);
not merged or approved for stable.

## Changes since immutable v2026.11.1.5

- New **Electricity market price hour rank** sensor (1 = cheapest physical
  local-day hour), and **Electricity market in cheapest hours** binary sensor.
  The default is four cheapest market hours per day, configurable from 1
  through 12 in Options for both authenticated and anonymous configurations.
  No additional GraphQL requests or entity-ID migration required.
- Market-component `market_price` is explicitly **not** a Belgian
  `MODEL` customer billing rate. These are market-price steering signals,
  *not* guaranteed invoice savings or supplier contract rates.
- PT15M source slots are aggregated to time-weighted physical hourly
  market prices. DST start has 23 hours and DST end 25 (including both
  occurrences of the repeated hour). Deterministic tie-break is UTC time.
  Any incomplete, contradictory or non-finite market input makes both
  automation states unavailable rather than falsely selecting cheapest slots.
- New optional per-service diagnostics **API status** and **Last successful
  API response** (disabled by default). Differentiates `not_checked`,
  `connected`, `error` and HTTP 429 `rate_limited` from observed
  provider calls. A disk-cache restore never becomes a fabricated API success.
- Options are localized for Dutch, Belgian Dutch, English and French.
  Existing electricity/gas min/max/average, cache, finance and hardware
  capabilities remain available without duplicate tariff devices.

2. Choose an integer X via Options. Compare the 24 current-day hourly market

3. Compare current vs missing tomorrow prices and a partial-day simulation:
   no cheapest-hour assertion without full-day evidence. Verify local

4. Optionally enable API status / Last successful API response per service,
   refresh once and compare with privacy-safe source diagnostics; on cache
   restart, status may correctly be `not_checked`.
5. Validate actual Belgian MODEL and gas publication lags, financial source
   completeness, HACS upgrade and rollback. Real customer tariff conversion,
   meter peak measurements, invoice reconciliation and Recorder acceptance
   remain **outside** this automatic green-test proof.

## Intentional scope separation

Manual margins and VAT would be *estimates* and must never replace the
supplier's authoritative customer rate. Vlaamse capaciteitstarief belongs
in RHI Energy with P1/import quarter-hour measurements, grid-operator-specific
rates and rolling monthly peak history—not a single EUR/kWh surcharge inside
the Frank supplier integration. Adaptive exponential retry remains a separately
qualified enhancement; the existing bounded 5/15/60-minute schedule applies.
