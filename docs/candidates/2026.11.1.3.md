# Frank Energie 2026.11.1.3 — midnight recovery HACS TEST

**Test-only prerelease.** Existing branch / Draft PR #18, unchanged main.

## Verified source problem

Installed 2026.11.1.2 diagnostics after 2026-11-01 midnight reported
unavailable prices, false electricity/gas flags and missing billing/usage
data despite coordinator success. The user independently proved that
**Refresh Prices** then populated actual electricity prices. HA Activity
is not the API call trace.

## Improvements

- Hourly automatic recovery of stale/missing current-day prices, missing
  authenticated site metadata and entirely absent finance source data,
  ordered settings -> statistics -> prices.
- No recovery API calls during the existing 00:00-01:00 UTC maintenance
  window. Automatic retry resumes after that window; the release window
  still refreshes at quarter-hour boundaries.
- Empty authenticated UserSites is no longer treated as a successful
  no-contract setting.
- Automatic vendor JWT renewal now persists its rotated access/refresh
  tokens to the HA config entry; avoids redundant writes and preserves
  the vendor API call behavior.
- Diagnostics report redacted recovery attempts/outcomes, maintenance
  skips, missing customer site metadata and price liveness.
- Regressions cover token persistence, missing metadata, post-maintenance
  recovery, and suppressed maintenance calls.

## Qualification / remaining gates

This is a new immutable HACS TEST candidate. Exact-head Python 3.14/
3.14.2 pytest and Flake8, Ruff, Quality Scale, Link Check, HACS,
Hassfest, asset/checksum verification must all pass. Existing releases
remain untouched. Install on the existing config entry, do not delete
devices or Recorder history. Prove unattended price/contract/usage
recovery after 00:00-01:00 UTC maintenance and validate gas/finance
provider coverage independently before stable promotion. Finance stays
opt-in and does not assert invoice settlement reconciliation.
