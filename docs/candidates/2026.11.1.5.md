# Frank Energie 2026.11.1.5 — Belgian restart diagnostics and time-coverage correctness

**HACS TEST only.** Candidate on the single active PR #18; not a stable release or a merge of `main`.

## Changes after immutable v2026.11.1.4

- New `source_check_evidence` diagnostic matrix explicitly distinguishes each expected supplier GraphQL source after startup. States: `source_present`, `source_null`, `source_empty`, `source_not_in_response`, `request_failed`, `disabled_by_option`, `not_applicable_*`, and `not_observed_in_retained_trace`.
- Separates public `MarketPrices` from customer `customerMarketPrices` even though the pinned client uses GraphQL operation name `MarketPrices` for both. MonthInsights is strictly associated with its current or previous `YYYY-MM` request.
- Shows missing/disabled finance checks without falsely declaring failed coordinator initialization. Source-root existence is **not** proof of meter freshness, all-day gas coverage, or invoice reconciliation.
- Source-check evidence reads only the existing bounded 96-event redacted GraphQL observer. It makes **zero additional API calls** and stores no site IDs, tokens, monetary readings or invoice details.
- Shared price interval-coverage implementation replaces fragile record-count comparisons when preserving local-day cached electricity/gas; overlapping/duplicate records are deduplicated, and 23/25-hour DST days are handled using exact UTC intervals.
- Automated regression coverage for cache intervals, source status, anonymous/customer isolation, monthly periods, errors and privacy; no entity/device unique ID, recorder history or provider control semantics are changed.

## Explicit limits

No new API source checks are forced by this release; the diagnostic matrix tells which requests actually happened after restart. Some smart services are conditional on supplier entitlement and do not imply missing checks when absent. The trace retains at most 96 events, so `not_observed_in_retained_trace` is not necessarily `never_checked`.

**Do not promote stable or merge PR #18** until exact-head CI, HACS/Hassfest, real HA device and Recorder evidence, authenticated MODEL tariff/source provenance, gas completeness, month finance source presence/units and invoice reconciliation are accepted. Prior tags/ZIPs remain immutable.
